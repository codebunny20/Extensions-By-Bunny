# Unit Converter Extension

This is a simple unit converter extension for your browser. It allows users to convert between various units of measurement through a user-friendly popup interface.

## Features

- Convert between different units of length, weight, and temperature.
- Easy-to-use interface with real-time conversion results.
- Lightweight and efficient.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/unit-converter-extension.git
   ```

2. Navigate to the extension directory:
   ```
   cd unit-converter-extension
   ```

3. Load the extension in your browser:
   - For Chrome: Go to `chrome://extensions/`, enable "Developer mode", and click "Load unpacked". Select the extension directory.
   - For Firefox: Go to `about:debugging#/runtime/this-firefox`, click "Load Temporary Add-on", and select the `manifest.json` file.

## Usage

1. Click on the extension icon in the toolbar.
2. Enter the value you want to convert.
3. Select the units you want to convert from and to.
4. The converted value will be displayed in real-time.
