# TabSearch Extension

TabSearch is a browser extension that enhances your browsing experience by providing a powerful search functionality across your open tabs. This extension allows users to quickly find and navigate to specific tabs based on their titles or content.

## Features

- Search through all open tabs.
- Highlight matching results for easy identification.
- User-friendly popup interface.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/TabSearch.git
   ```
2. Navigate to the extension directory:
   ```
   cd TabSearch/extension
   ```
3. Load the extension in your browser:
   - For Chrome: Go to `chrome://extensions/`, enable "Developer mode", and click "Load unpacked". Select the `extension` folder.
   - For Firefox: Go to `about:debugging#/runtime/this-firefox`, click "Load Temporary Add-on", and select the `manifest.json` file.

## Usage

1. Click on the TabSearch icon in your browser toolbar.
2. Enter your search query in the popup.
3. View the highlighted results and click on any result to navigate to the corresponding tab.
